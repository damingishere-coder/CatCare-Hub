# P2｜客户档案执行任务

## 背景

P0 已建立本地 Web 管理后台和 Windows 启停入口，P1 已建立客户、猫咪及后续业务所需的数据模型、迁移和安全 Seed。正式开发文档要求 P2 在 `/admin/customers` 完成客户列表、搜索、客户新增/编辑/查看，以及一个客户下多只猫咪的新增、编辑和停用，覆盖门禁、钥匙和服务注意事项。

## 目标

1. 建立仅供本地后台使用的客户与猫咪 API。
2. 在 `/admin/customers` 建立客户列表、搜索、详情和表单交互。
3. 支持完整录入和编辑客户基础信息、地址、门禁、钥匙、备注与老客户状态。
4. 支持一个客户添加、编辑和停用/恢复多只猫咪，并记录饮食、猫砂、用药、特殊情况和服务注意事项。
5. 以自动测试和 Windows 实际启动验证完整业务闭环。

## 允许修改范围

- `backend/app/api/`：P2 客户与猫咪路由。
- `backend/app/schemas/`：P2 请求与响应模型。
- `backend/app/main.py`：挂载 P2 Router。
- `backend/tests/`：客户/猫咪 API 测试。
- `frontend/src/features/customers/`：客户 API、类型、表单和页面组件。
- `frontend/src/pages/admin/`、`frontend/src/routes/`：接入客户档案页面及测试。
- `frontend/vite.config.ts`：本地开发 API 代理。
- `README.md`、`DEVELOPMENT_PROGRESS.md` 和本任务文件。

## 禁止修改范围

- 不实现 P3 订单、费用计算或任务生成。
- 不实现 P4 排程、P5 地图路线、P6 图片上传或任务执行。
- 不实现 P8 收款页面、P9 手机执行业务、P10 客户填写 Token/提交、P11 PWA 或 P12 完整鉴权。
- 不删除客户，不物理删除猫咪或破坏未来订单历史关联。
- 不把门禁、钥匙编号、详细地址等敏感字段放入客户列表批量响应、日志、测试快照或前端持久化存储。
- 不提交真实客户/猫咪资料、数据库、上传图片、`.env`、日志或运行状态文件。
- 不引入无必要的前端状态库、组件库或重度 UI 设计。

## 已确定实现要求

- API 使用 `/api/admin/customers` 前缀；外网部署时仍只允许未来的 `/fill/*`，不得公开后台及本 API。
- `GET /api/admin/customers` 只返回列表所需的非敏感摘要和猫咪数量；`POST /api/admin/customers/search` 通过 JSON 请求体搜索姓名、微信昵称、手机号、小区和猫咪名字，避免手机号进入访问日志 URL。
- `POST /api/admin/customers`、`GET/PATCH /api/admin/customers/{id}` 完成客户新增、查看和编辑。
- `POST/PATCH /api/admin/customers/{id}/cats...` 完成猫咪新增、编辑、停用与恢复；停用通过 `is_active` 软状态实现。
- 客户详情返回完整客户信息及所有猫咪（包含已停用），让历史状态可见且可恢复。
- 请求模型统一去除字符串首尾空白，把可选空字符串转为 `null`；客户名和猫咪名必填，年龄必须处于数据库可表示的非负范围。
- 不在本轮新增数据库表或迁移；P1 的 Customer/Cat 字段已覆盖 P2。
- 前端采用同页“客户列表 + 客户详情”主从布局，并提供清晰的加载、空、错误和保存状态。
- 客户表单覆盖文档中的全部客户字段；猫咪表单覆盖现有模型中的全部档案字段。`photo_url` 仅保留可选路径/URL 字段，本轮不实现文件上传。
- 前端不得在 `localStorage`、日志或 URL 查询参数中保存门禁、钥匙、手机号和详细地址。
- Vite 本地开发服务器将 `/api` 代理到 `127.0.0.1:8000`，保证 `start.bat` 下前后端联通。

## 验收标准

1. 可以新增一个客户，完整保存并重新读取姓名、联系方式、地址、门禁、钥匙、备注与老客户状态。
2. 可以为同一客户新增至少两只猫咪，并完整保存饮食、用药、特殊情况与服务注意事项。
3. 可以编辑客户和猫咪；可以停用和恢复猫咪，且不会物理删除记录。
4. 客户列表支持按客户姓名、微信昵称、手机号、小区或猫咪名字搜索，并显示活动/停用猫咪数量。
5. 客户列表响应不包含门禁、入户信息、钥匙编号或完整客户备注。
6. 不存在的客户、错误的猫咪归属和非法输入返回明确的 `404`/`422`，不泄露其他客户详情。
7. `/admin/customers` 可在 Windows 本地启动环境完成新增客户、添加多只猫咪、编辑与停用闭环。
8. P0/P1 的健康检查、迁移、Seed、前端路由和 Windows 启停保持通过。
